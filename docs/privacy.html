Privacy Policy

Job Application Agent is a personal-use application.

Data accessed

The application reads Gmail messages to identify job application events and accesses Google Sheets to read and update application tracking records.

Data processing and storage

Relevant message content is processed through Google Cloud Vertex AI. Extracted application information is stored in Google Sheets, while message identifiers and review records are stored in Google Cloud Firestore. Operational information may be stored in Cloud Logging.

Data use and sharing

Google user data is used only to operate the personal application tracker. It is not sold or used for advertising. Processing and storage use the Google Cloud services described above.

Retention and control

Application records remain until deleted by the owner. Operational logs follow the configured Google Cloud retention settings. Google account permissions can be revoked through Google Account settings.

Contact

For privacy inquiries, contact the developer using the support email on the Google OAuth consent screen.
